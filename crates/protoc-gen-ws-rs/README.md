# protoc-gen-ws-rs

A `protoc` plugin that emits ws-proto (WebSocket RPC) service bindings for Rust
on top of message types generated by
[`protoc-gen-prost`](https://github.com/neoeinstein/protoc-gen-prost). It is to
ws-proto what `protoc-gen-tonic` is to gRPC, and is built on the same
`protoc-gen-prost` library.

Run it after `protoc-gen-prost` with the **same `out`**: for each protobuf
package it writes `<package>.ws.rs` and appends `include!("<package>.ws.rs")` to
the package's prost file through the `module` insertion point.

## Options

| Option | Effect |
|---|---|
| `default_package_filename=<v>`, `flat_output_dir`, `extern_path=<proto>=<rust>`, `compile_well_known_types` | Mirror the `protoc-gen-prost` step so type paths resolve identically. |
| `no_server` / `no_client` | Skip generating one side. |
| `no_include` | Do not append the `include!` to the prost file. |

## Usage with easyp / buf

```yaml
plugins:
  - name: prost          # protoc-gen-prost
    out: gen/src
    opts: { bytes: "." }
  - name: ws-rs          # protoc-gen-ws-rs
    out: gen/src
  - name: prost-crate    # protoc-gen-prost-crate
    out: gen
    opts: { gen_crate: Cargo.toml.tmpl }
```
